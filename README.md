# ✨ Shine Joias — Prata 925

> **Não é qualquer prata, é Shine.** Joias em Prata 925 legítima, garantia vitalícia, catálogo digital interativo e atendimento direto via WhatsApp.

---

## 💎 Sobre o Projeto

Website oficial e catálogo interativo da **Shine Joias**, desenvolvido com foco em alta conversão, experiência visual luxuosa e navegação fluida em dispositivos móveis e desktops.

### ✨ Principais Funcionalidades

- 🎬 **Intro Cinematográfica**: Vídeo de abertura em tela cheia com áudio imersivo, exibido apenas no primeiro acesso por aba (`sessionStorage`), com opção de rever a qualquer momento pelo botão *"Ver intro"*.
- 🎠 **Hero Slider Dinâmico**: Carrossel responsivo com transição de slides apresentando a assinatura da marca, a coleção de Alianças e a Linha Masculina em Prata 925.
- 🏷️ **Navegação por Categorias**: Cards visuais com fotografia de estúdio em alta resolução para Alianças, Anéis, Brincos, Colares, Pulseiras e Linha Masculina.
- 💍 **Seção Especial de Alianças**: Destaque para alianças de compromisso, namoro e noivado com guia integrado de medidas de aro.
- 🛍️ **Catálogo & Vitrine Interativa**:
  - Filtros instantâneos por categoria (Todos, Alianças, Anéis, Colares, Pulseiras, Brincos, Masculino).
  - Fotos reais de estúdio em fundo branco para cada peça.
  - Preços em destaque e parcelamento.
  - Modal de detalhes da peça com especificações e certificado de garantia.
- 📲 **Checkout Direto via WhatsApp**:
  - Adição de itens ao carrinho com controle de quantidade.
  - Gaveta lateral de sacola / carrinho.
  - Geração automática de mensagem formatada com os itens escolhidos e envio com 1 clique para o WhatsApp da loja.
- 📐 **Medidor de Aro Interativo**: Passo a passo com régua / fita métrica para o cliente descobrir o tamanho exato da aliança antes de fechar o pedido.
- 🛡️ **Garantia Vitalícia & Guia de Cuidados**: Orientações de conservação da prata 925 (limpeza com flanela mágica, armazenamento e cuidados diários).
- 📍 **Localização & Horários**: Seção de atendimento presencial e suporte online.

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**
- **CSS3 Moderno**: Variáveis CSS (Custom Properties), Flexbox, CSS Grid, tipografia fluida com `clamp()`, animações e transições aceleradas por hardware.
- **JavaScript Vanilla (ES6+)**: Sem dependências externas ou frameworks pesados, garantindo carregamento ultrarrápido e performance 100/100.
- **Design Responsivo**: Adaptado para telas móveis (iOS e Android), tablets e monitores ultrawide.

## 📦 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/phfirminodev/Shine-Joias.git
   ```
2. Navegue até o diretório:
   ```bash
   cd Shine-Joias
   ```
3. Abra o arquivo `index.html` em qualquer navegador moderno ou utilize uma extensão de servidor local como o **Live Server** do VS Code.
